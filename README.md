# HOLIC GEM 2.0

홀릭잼 2.0 — 유저 앱(Expo) / 본사 관리자(웹) / API 서버. 실서비스 기반 코드.

## 구성

```
holicgem/
├─ apps/
│  ├─ api/       NestJS API 서버 (포트 4000)
│  ├─ admin/     본사 관리자 웹 — Next.js (포트 3000)
│  └─ mobile/    유저 앱 — Expo (iOS·Android·웹)
└─ packages/
   └─ db/        Prisma 스키마 + 시드 + 개발용 내장 PostgreSQL (포트 5433)
```

## 핵심 설계

| 제안서 항목 | 구현 |
|---|---|
| 혜택 자격 통합 | 멤버십 구매 / 상품(PASS) 구매 / 수동 지급 → 전부 `UserBenefit` 하나로 모임. 쿠폰을 찾아 받는 단계가 없음 |
| 오늘의 DROP | 수량·시간 한정, 멤버 전용/선오픈, 광고 표기, 트랜잭션 수량 차감(초과 판매 불가) |
| 결제→예약 완결 | 예약형 상품은 날짜·시간·인원 → 결제 → 예약확정까지 앱 안에서 끝남 (전화 예약 없음) |
| 현장 사용 | 가맹점 고정 QR을 손님이 스캔 → 그 매장에서 쓸 수 있는 것만 표시 → 사용처리 |
| 완료화면 위조 방지 | 실시간 시계 + 90초 카운트다운 + 6자리 직원 확인 코드(가맹점 모드에서 조회) |
| 절약액 표시 | 사용 기록마다 절약액 계산 → "이번 달 얼마 절약 / 멤버십 회수율 %" |
| 가맹점 부담 0 | 장비·직원 앱·교육 불필요. QR 스티커만 비치, 점주만 가맹점 모드 사용 |
| 결제 | PG 확정 전까지 `Payment.provider = MOCK`. PG 결정 후 provider 구현만 교체 |

## 실행 (터미널 4개)

```bash
npm install                # 최초 1회, 루트에서

아래 순서로 실행:

# ① 개발 DB (내장 PostgreSQL — 별도 설치 불필요)
npm run dev:db -w @holicgem/db

# ② (최초 1회) 스키마 반영 + 시드
npm run db:push
npm run db:seed

# ③ API 서버
npm run api

# ④ 관리자 웹  → http://localhost:3000
npm run admin

# ⑤ 유저 앱 (웹 미리보기 → http://localhost:8081, 폰은 Expo Go로 QR 스캔)
npm run mobile
```

> 한글 경로 주의: 이 저장소는 한글 폴더 아래에 있어도 동작하도록 개발 DB 데이터·바이너리를
> `%LOCALAPPDATA%\holicgem-pgdata`, `holicgem-pgbin` (ASCII 경로)에 둡니다.

## 데모 계정

| 역할 | 로그인 |
|---|---|
| 관리자 (웹) | admin@holicgem.com / admin1234 |
| 일반 회원 (앱) | MY 탭 → "카카오로 시작" (데모 계정 자동 로그인) |
| 점주 (앱) | 소셜 로그인 후 MY 탭에 "가맹점 모드" 노출 — 시드: 서프홀릭 송정본점 / 까사부사노 |

앱은 소셜 간편가입만 지원(비밀번호 없음). 개발 모드에서는 provider+ID로 즉시 로그인되며,
실서비스 전환 시 `apps/api/src/auth.ts`의 `social()`에 각 소셜 토큰 검증만 추가하면 됩니다.

## 데모 흐름 (5분)

1. 관리자 웹 로그인 → 대시보드 · DROP 승인 대기 확인
2. 가맹점 → 아무 매장 "QR 보기" (이 QR이 매장 카운터에 붙는 것)
3. 유저 앱 → 카카오로 시작 → MY에서 멤버십 구매(모의결제) → **혜택 탭에 11개 자동 오픈**
4. 오늘 탭 → DROP 받기 / 서핑 상품 예약(슬롯+인원 → 결제 → 예약확정)
5. 사용 탭 → 매장 QR 코드 입력(웹) 또는 카메라 스캔(폰) → 사용하기 → **완료화면(실시간 시계+확인코드)**
6. 점주 계정 → 가맹점 모드 → 방금 코드 조회로 검증, 오늘 사용내역 확인
7. 관리자 → 사용내역에서 CS 취소 시 상태 복구 + 감사 로그

## 실서비스 전환 시 바꿀 것

- `DATABASE_URL` → 운영 PostgreSQL (dev-db 스크립트는 개발 전용)
- `JWT_SECRET` 교체
- 소셜 로그인: 카카오/네이버/구글/애플 토큰 검증 추가 (`auth.ts` social)
- 결제: PG사 확정 후 `Payment.provider` 구현 교체 (주문/이용권 로직은 그대로)
- 푸시 알림: `UserDevice` 테이블 준비돼 있음 — FCM 발송만 연결
